# Overview

**MOBYD** is a mobile monitoring and tracking system for your business.

You can integrate **MOBYD** into your existing application (mobile, web, or desktop) to monitor and track events and
activities.

:::info

**MOBYD** does not have a public version yet. Please [contact me](https://twitter.com/KenanBekk) if you are interested in this project.

:::
