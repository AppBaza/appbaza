# AppBaza

[AppBaza](https://appbaza.com) is a one-person tech company focusing on open-source and open-core projects.

## Projects

Most of my projects come out of my needs from different personal initiatives.

Currently, I am focusing on the following areas:

* Ready-to-use project templates with already integrated management dashboards and 3rd party integrations. An example is
  the Next.js project with an already integrated Stripe and an admin management dashboard where you can see and manage
  subscriptions. Follow the [NEST](/nest) project for more information.
* Tooling for monitoring your products and tracking certain events like registration, sale, and errors. With a mobile
  client and an API to integrate. Follow the [MOBYD](/mobyd) project for more information.
* Set of ready-to-use AI API integrations with some advanced features on top of it. I will share more details soon.

## Process

My work process is as follows:

1. Prepare high-level design and initial specification (API specification, for example). Add to documentation.
2. Define integration points and write them down. Usually, this also ends up in the documentation.
3. Start the work piece by piece, and iterate.

Most of the time, documentation for the project is available even before the project is published. But this might change
after a couple of major iterations.

## What's next?

The primary goal, for now, is to get mentioned projects ready for early access and, in parallel, extend their
documentation.
