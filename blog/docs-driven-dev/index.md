# DDD: Documentation Driven Development

I follow the Documentation Driven Development (DDD) for a while now, and I am very happy with the results.

## What is DDD?

DDD (not to be confused with Domain Driven Design) is a process where you start with the documentation and then start
the development.

## Why DDD?

I found that this process helps me to focus on the most important things and not to get lost in the details.

But it also helps me to think about the project from the user's perspective and not from the developer's perspective.

Additionally, it also helps me to have a clear picture of the project and its scope.
