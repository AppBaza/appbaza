## [NEST](/nest) change logs

### 0.5.0 (September, 2023)

- Core/Project API: Add project features
- Base/Item API: Filter by `meta` json field (json query)
- Base/Item API: Save `innerObject` as a custom json content
- Base/Item API: Filter by `innerObject` json field (json query)
- Base/Item API: New `/item/search` endpoint for advanced filtering
- AI/OpenAI API: Add `gpt-3.5` and `gpt-4` models

### 0.4.0 (August, 2023)

- Core/Profile: Add Register and Login endpoints
- Core/Profile: Add Authentication with JWT Token
- Base/Item API: Add new fields: `type`, `group`, `category`
- Base/Image API: Resize image
- Base/PingPong API: Simplify API by separating it into stateless and stateful endpoints

### V0.1.0 (Early August, 2023)

- Add PingPong API for testing
- Add initial documentation for [API for List and Detail views](/docs/nest/api-for-list-detail-views) feature
